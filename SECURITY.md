# Política de seguridad

No publique vulnerabilidades con datos de un servidor real en una incidencia pública. Prepare un informe que incluya versión, pasos mínimos de reproducción, impacto y registros previamente censurados. Nunca adjunte tokens de Jellyfin, cookies, rutas privadas, nombres de usuario reales ni copias de la base de datos.

El plugin no incorpora telemetría. La autenticación procede exclusivamente de Jellyfin y la autorización vuelve a comprobarse en cada endpoint. Los adjuntos se limitan a imágenes JPEG, PNG o WebP reconocidas por su firma binaria.
