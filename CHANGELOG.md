# Changelog

## 1.0.0.0 — 2026-08-05

- Versión estable dirigida a Jellyfin Server 10.10.7 y .NET 8.
- Referencias oficiales Jellyfin 10.10.7 y ABI objetivo 10.10.7.0.
- API REST autenticada, página Comunidad integrada en el menú y configuración administrativa.
- Categorías generales o vinculadas a bibliotecas; debates, reseñas, anuncios y encuestas.
- Mensajes Markdown seguro, citas, menciones, reacciones, seguimiento y borradores.
- Spoilers según el estado visto de Jellyfin y control de visibilidad por elemento.
- Notificaciones locales, denuncias, moderación, suspensiones, silenciamientos y auditoría.
- SQLite independiente con WAL, migraciones, integridad, optimización y tareas programadas.
- Adjuntos JPEG, PNG y WebP con validación binaria, nombres seguros, límites y cuota global.
- Copias consistentes mediante snapshot SQLite y restauración validada con control de rutas, tamaño, ABI, SHA-256 e `integrity_check`.
- Compilación Release con analizadores, advertencias como errores, pruebas con cobertura y auditoría de dependencias.
- Paquete mínimo que no sustituye ensamblados proporcionados por Jellyfin.
